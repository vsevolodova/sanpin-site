# Дизайн-система 

# Формат: 
Строго 16:9. Каждый слайд имеет фиксированную высоту 100vh (без внутренней прокрутки). Базовое разрешение макета: 1920×1080 px.

# Цвета:
 Глубокий графит/темно-синий фон. Акцентный цвет: холодный cyan / electric blue. Текст: белый и светло-серый.
# Типографика:
 Основной шрифт — Manrope.
# Заголовки:
 крупные (52-72px), выразительные.
Kicker / надзаголовки (типа «ПМК-2 · система контроля качества»): вес Semibold (не тонкие, не жирные до слипания букв).
# Основной текст:
 18-20px, комфортный line-height (буквы не должны наезжать друг на друга).
# Графика:
Фоны слайдов должны быть яркими/контрастными, но с правильным overlay (затемнением) для читаемости текста.
Избегать «картинок в странных рамках».
Архитектурные схемы должны быть интегрированы в фон или занимать 40-60% слайда.
Генерируй иллюстрации для фоновых слайдов вкусной реальной фототекстурой из тематики российского пищеблока.
Графика должна быть не «картинка рядом», а смысловой центр слайда. 

# Иконки: 
Только смысловые inline-SVG.
